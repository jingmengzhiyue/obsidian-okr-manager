# Vault OKR Manager 1.5.0 — Optional KR drafts and safer interactions

Requires Obsidian 1.7.2 or later. Existing Markdown, YAML, history and review snapshots remain compatible. No new production dependency or data migration.

- Create an Objective with zero, one or multiple KR drafts. Draft cards remain in memory until one complete Objective file is created. Standalone KR creation remains available.
- Owner is an optional personal text note in all Objective and KR forms. KR owner/deadline inherit until manually edited; dashboard creation uses the viewed period.
- Postponing an overdue Objective defaults to today; otherwise it defaults to the day after the old deadline. Today/+7/+30 shortcuts never save automatically. Historical adjustments remain valid when later than the old deadline. Only the Objective deadline changes, not its period or KR deadlines.
- Preserve manually edited or cleared deadlines, with an explicit action to restore the period default.
- Reject stale prefilled objects, ignore out-of-order loads, and offer retries. Review actions keep their row’s original period.
- Ordinary Enter does not submit. Saving prevents duplicate submissions and cancellation; navigation/refresh failures after a successful write cannot create duplicate data.
- Revalidate numbers when units or linked check-in fields change. Boolean limits have specific messages; every finite positive relative weight, including 0.05, remains supported.
- Explain that KR edits/deletions inside Edit Objective save immediately, independently of unsaved parent fields.

## 中文说明

新增可选 KR 草稿联合创建：目标可以没有 KR，也可以在同一窗口填写一条或多条，全部一次写入原有 Markdown 文件。独立新建 KR 的入口保留。负责人为可选个人备注，不引入账号或协作配置。

延期按本地自然日提供默认值和快捷日期，保留历史调整能力，仅修改 Objective 截止日期。手动填写或清空的日期及继承字段不会被周期/父目标变化覆盖。

修复失效预填、异步加载乱序、宽泛 Enter 提交、保存后导航失败导致重复创建，以及单位切换和 Check-in 联动残留错误。编辑目标中的 KR 操作仍立即保存，并在界面明确说明。

## Validation / 验证边界

发布前已重新运行全部 **175 项自动化测试**、ESLint、TypeScript/生产构建及 Git 差异格式检查，全部通过。此前的 Node 回归及 Windows Chromium 独立 DOM 检查记录见 [实施验证记录](https://github.com/jingmengzhiyue/obsidian-okr-manager/blob/1.5.0/docs/testing/2026-09-16-okr-interactions.md)。真实 Obsidian 原生日历弹出月份、系统中文输入法、移动端与实际主题兼容性仍需在专用测试 Vault 验收。

## Installation / 安装

Download **main.js**, **manifest.json**, and **styles.css** from this release, copy them into `<vault>/.obsidian/plugins/vault-okr-manager/`, and reload Obsidian. The automatically generated source archives are not installable plugin builds.

手动更新时，下载本次 Release 的 **main.js**、**manifest.json** 和 **styles.css**，放入 `<vault>/.obsidian/plugins/vault-okr-manager/` 后重新加载 Obsidian。自动生成的源码压缩包不能直接作为插件安装包。
